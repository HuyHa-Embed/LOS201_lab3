# LAB-03: Kernel Debugging & Performance Analysis

## Giới thiệu
Bài thực hành tập trung vào các kỹ thuật Debugging và phân tích hiệu năng ứng dụng trong môi trường Embedded Linux trên kiến trúc ARMv7.

## Nội dung thực hiện
- Debug ứng dụng ARM bằng GDB và gdbserver.
- Phát hiện và phân tích lỗi quản lý bộ nhớ bằng Valgrind.
- Theo dõi System Calls bằng strace.
- Phân tích hiệu năng CPU bằng perf.
- Tìm hiểu Kernel Debugging và phân tích Kernel Log.
- Đo lường và so sánh độ trễ giữa Standard Kernel và PREEMPT_RT Kernel.

## Công nghệ sử dụng
- GDB / gdbserver
- Valgrind
- strace
- perf
- cyclictest
- QEMU (ARMv7)

## Mục tiêu
Làm quen với các công cụ Debugging, phát hiện lỗi bộ nhớ và đánh giá hiệu năng của ứng dụng Linux nhúng.
